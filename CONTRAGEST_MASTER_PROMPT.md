# Contragest Master Prompt: High-Fidelity Enterprise Dashboard

**Goal:** Recreate a professional Enterprise Contract Management Dashboard (Contragest) with a high-density, "Cyberpunk-meets-Corporate" OLED Dark Mode interface.

---

### 1. Visual Identity & Design System (OLED Dark Mode)
- **Base Theme:** Use `ttkbootstrap` with the "superhero" theme as the foundation.
- **Color Palette (WCAG AAA Compliant):**
    - **Background:** `#020617` (True OLED Black)
    - **Surface/Cards:** `#1E293B` (Slate Blue)
    - **Primary Accent:** `#22C55E` (Vibrant Green for status and success)
    - **Danger/Expired:** `#FF4444` (Vivid Red)
    - **Warning/Expiring:** `#FFBB33` (Amber)
    - **Main Text:** `#F8FAFC` (High-contrast Off-white)
    - **Muted Text:** `#94A3B8` (Slate-400 for secondary information)
- **Typography:**
    - **Headings/Identity:** `Lexend` or `Playfair Display SC` (Clean, authoritative).
    - **Body/Technical Data:** `Source Sans 3` or `Fira Sans` (Optimized for data density and technical precision).

---

### 2. Layout Architecture (Enterprise Gateway)
- **Ribbon Menu:** Implement a top-docked Ribbon navigation bar. Group actions into logical tabs:
    - `🏠 Home`: Dashboard navigation, general settings, and session exit.
    - `👔 HR`: Employee and contract management shortcuts.
    - `🛠️ Tools`: User management and "Mouchard" (Audit logs).
    - `📊 Reports`: Quick access to specialized analytics.
- **SPA-style Content Area:** Use a `ttk.Notebook` with hidden tabs to switch between views (Home, Contracts, etc.), creating a seamless "Single Page Application" feel.
- **Hero Dashboard (Home Tab):**
    - Centered 300x300 company logo.
    - **Stats Bar:** A horizontal bar at the top displaying current counts for: `Active | Expiring Soon | Expired`.
- **Sophisticated Status Bar:** A persistent 4-part bar at the bottom:
    - **PC Info:** `💻 [hostname] ([local_ip])`
    - **Session:** `Logged in as: [username] ([role])`
    - **Environmental Data:** `🌍 [City, Country] 🌡️ [Temp]` (Fetched via background scheduler).
    - **Live Clock:** `📅 dd/mm/yyyy 🕒 HH:MM:SS` (Updated every second).

---

### 3. Core Logic & Components
- **Advanced Tableview (Contract Management):**
    - **Columns:** Edit (Icon), Delete (Icon), ID, First Name, Last Name, Type, Start Date, End Date, Seniority, Days Left, Status.
    - **Flashing Alerts:** Rows for "Expired" or "Expiring Soon" must flash with a smooth 800ms interval.
        - *Danger State:* Alternates between `#ff4444` and `#d9534f`.
        - *Warning State:* Alternates between `#ffbb33` and `#f0ad4e`.
- **Seniority Calculation:** Logic to dynamically compute seniority in "X months and Y days" since the contract's start date, accurately handling different month lengths.
- **RBAC Security:**
    - Conditional rendering of Ribbon tabs and buttons based on user role.
    - **Secure Deletion Formula:** To perform deletions or recovery, require a password generated by: `((day + month + (year % 100)) * 2) - 10`.
- **Reporting Engine:**
    - Multi-tabbed interface (Users, Spy/Audit, Employees, Contracts).
    - Advanced filtering: Global search + Column-specific dropdowns + Date range pickers.
    - Export support: CSV and high-fidelity PDF (using `fpdf2` with logo integration).

---

### 4. Technical Stack & Polish
- **Stack:** Python 3.12+, `ttkbootstrap`, `SQLAlchemy` (SQLite), `Pillow` (for image processing), `fpdf2` (PDF).
- **Interactive Polish:**
    - Replace all Unicode emojis with high-fidelity SVG icons (Lucide/Heroicons style).
    - Apply smooth transitions (150-300ms) for all hover states and button interactions.
    - Use an asynchronous `BackgroundScheduler` to update environmental data and trigger automated expiration alerts without blocking the UI.
